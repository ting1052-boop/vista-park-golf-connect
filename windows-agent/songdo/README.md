# 송도파크자이 Agent 설치 패키지

타석 9대에 VISTA Bay Agent 를 설치한다. 시흥점과 **같은 실행파일**이고,
타석 설정의 `monitorOnly` 로 고객 화면과 Agent의 세션 만료 자동 처리를 끈다.

| | 시흥 | 송도 |
| --- | --- | --- |
| 남은시간 경고창 | 표시 | 표시 안 함 |
| 종료 후 잠금화면 | 표시 | 표시 안 함 |
| 이용 종료 후 자동 PC 종료 | 5분 뒤 | 하지 않음 |
| 대시보드 heartbeat | 보냄 | 보냄 |
| 게임상태 감지 | 시흥 프로그램 설정 사용 | 현장 프로그램 확인 전까지 `확인 불가` |
| 관리자 `PC 정상 종료` | 받음 | 받음 |

---

## 1. 개발 PC 에서 (한 번만)

### 빌드

```powershell
cd windows-agent
npm run dist:portable
```

`windows-agent\dist\VISTA-Bay-Agent.exe` 가 나온다.

### 토큰 만들기

```powershell
powershell -ExecutionPolicy Bypass -File .\songdo\토큰만들기.ps1
```

두 파일이 생긴다. **둘 다 비밀이다. 커밋 금지.**

```
songdo\songdo-tokens.json      설치 USB 용
songdo\등록SQL-작성됨.sql       Supabase 용
```

### Supabase 등록

`등록SQL-작성됨.sql` 을 SQL Editor 에서 연다.

1. **[1단계]** 만 실행한다. 송도 타석의 실제 `bay_code` 9개가 나온다.
2. **[2단계]** 의 `bay_code` 열과 `REPLACE_WITH_SONGDO_STORE_CODE` 를 그 값으로 고친다.
3. **[2단계]** 를 실행한다. `returning` 이 **9행**이어야 한다. 그보다 적으면 `bay_code` 철자가 다른 것이다.

### USB 준비

이 네 개만 USB 에 넣는다.

```
VISTA-Bay-Agent.exe
songdo-tokens.json     ← 비밀
Agent설치.bat
install-agent.ps1
```

**`등록SQL-작성됨.sql` 은 USB 에 넣지 않는다.** 그 안에도 토큰 9개가 평문으로 들어
있다. Supabase 에 붙여넣는 일은 개발 PC 에서 끝내고, 붙여넣은 뒤 파일을 지운다.

## 2. 각 타석 PC 에서

### 먼저 — 어떤 계정으로 실행하는가

Agent 설정과 자동실행은 **실행한 계정의 프로필**에 저장된다. 손님이 골프를 칠 때
로그인돼 있는 그 계정으로 실행해야 한다.

- `Agent설치.bat` 을 **그냥 더블클릭**한다. `관리자 권한으로 실행`을 쓰지 않는다.
- UAC 창이 떠서 **다른 관리자 계정**으로 승격하면, 그 계정 폴더에 토큰이 들어가고
  평소 계정으로 로그인했을 때 Agent 가 뜨지 않는다.
- 그래서 설치 위치도 `C:\VISTA` 가 아니라 `%LOCALAPPDATA%\VISTA` 다. 권한이 필요 없다.

설치기가 맨 처음 계정 이름을 보여주고 확인을 받는다. 다르면 거기서 멈춘다.

### 순서

`Agent설치.bat` 더블클릭 → **계정 확인** `y` → **타석 번호 선택** → `y`

ZIP 안에서 바로 실행하지 말고 **네 파일을 모두 압축 해제**한 뒤
`songdo-tokens.json`을 같은 폴더에 추가한다. 설치 BAT를 실행하면 검은 창에
계정 확인 질문이 떠야 한다. 창이 곧바로 닫히거나 질문이 없다면 압축 해제한
폴더의 주소창에 `cmd`를 입력해 연 다음 `Agent설치.bat`을 실행한다.
나오는 오류 문구를 확인하고, 설치 완료로 간주하지 않는다.

설치기가 하는 일:

```
그 타석 토큰 하나만 이 PC 에 저장  (나머지 8개는 저장하지 않는다)
exe 를 %LOCALAPPDATA%\VISTA 로 복사
그 계정 시작프로그램에 등록
설정과 자동실행이 같은 프로필인지 확인
Agent 실행
```

설치가 끝난 뒤 **Agent 자체는 화면에 아무것도 띄우지 않는다.** 설치 BAT의
검은 안내창은 보여야 한다.

### 첫 대(파크 1번) 합격 기준

확대하기 전에 이 네 가지가 다 되어야 한다.

1. 2분 안에 대시보드에서 `PC 켜짐`
2. 무인제어에서 `PC 정상 종료` → 실제로 Windows 가 정상 종료
3. HA `타석 전원` 에서 켜기 → 부팅
4. **로그인만 하면** 다시 `PC 켜짐` (자동실행 확인)

4번이 이 설치에서 가장 잘 깨지는 부분이다. 계정이 어긋나면 1~3 은 되는데
4 만 안 된다.

그 뒤 하루 두고 보고 나머지 8대로 넓힌다.

### 9대가 끝나면

**USB 에서 `songdo-tokens.json` 을 지운다.** 그 파일 하나에 9대 토큰이 전부 있다.
개발 PC 의 `등록SQL-작성됨.sql` 도 같이 지운다.

## 확인·문제 해결

설정과 로그는 여기 있다. `%APPDATA%\VISTA Bay Agent` 가 **아니다.**

```
%APPDATA%\vista-windows-agent\
    bays.config.local.json          이 타석 토큰
    agent.config.json               선택한 타석
    logs\vista-agent-overlay.log    동작 기록
```

| 증상 | 원인 |
| --- | --- |
| 대시보드가 계속 `PC 확인 안 됨` | 로그에 `401` 이 있으면 토큰 미등록. SQL [2단계]를 실행했는지 확인 |
| 로그에 아무것도 없다 | Agent 가 안 떴다. `%LOCALAPPDATA%\VISTA\VISTA-Bay-Agent.exe` 를 직접 실행해본다 |
| 타석을 잘못 골랐다 | `Agent설치.bat` 을 다시 실행하고 맞는 타석을 고른다 |
| 고객 화면에 경고창이 뜬다 | `monitorOnly` 가 안 먹은 것. 타석 코드가 `SD-` 로 시작하는지 확인 |
| 재부팅하면 `PC 확인 안 됨` 인데 수동 실행하면 켜짐 | 계정이 어긋난 것. 평소 로그인 계정으로 `Agent설치.bat` 을 다시 실행한다 |
| 9대 중 일부만 등록됐다 | SQL [2단계]는 9개가 다 맞아야만 넣는다. 일부만 등록될 수 없다. 그래도 그렇다면 [3단계] 조회로 확인 |

## 이 Agent 가 하지 않는 것

- **마감 시각에 PC 를 끄지 않는다.** 23:10 종료는 각 PC 의 작업 스케줄러가 한다(`WOL준비.bat`).
  Agent 는 관리자가 대시보드에서 누를 때만 끈다.
- **아침에 PC 를 켜지 않는다.** 05:50 기상은 HA 의 WOL automation 이 한다.
- **트레이 아이콘을 만들지 않는다.** Agent 가 죽으면 아이콘도 사라져 확인 수단이 못 된다.
  대시보드 `PC 켜짐` 이 그 역할을 한다.
