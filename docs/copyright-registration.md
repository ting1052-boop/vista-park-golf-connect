## 2. 프로그램의 목적 및 기능 요약

VISTA Park Golf Connect는 스크린파크골프 가맹점의 **무인·반무인 운영**을 지원하는
자체 개발 통합 시스템이다. 웹 서버(Next.js/Supabase), 매장 입구 키오스크,
타석 PC 상주 에이전트(Electron), 매장 로컬 제어기(PowerShell)의 4개 프로그램이
하나의 서비스로 유기적으로 동작한다.

1. **고객 모바일 예약** — 매장 선택, 날짜·시간 선택, 인원·이용시간 선택,
   타석 자동 배정, 예약 확인 요약, 예약 확정. PWA 방식으로 휴대전화 홈
   화면에 설치하여 앱처럼 사용 가능.
2. **입구 키오스크 무인 입장** — 예약 고객의 전화번호 뒤 4자리 조회 입장,
   예약 없는 현장 고객의 즉시 이용(타석 선택·이용시간 선택·후불 계좌이체
   안내)까지 사람 개입 없이 처리.
3. **예약 충돌 방지** — 응용 계층의 실시간 가용 타석 계산과 데이터베이스
   계층의 배타 제약조건(exclusion constraint)을 이중으로 적용하여 동일
   타석·동일 시간대 이중예약을 원천 차단.
4. **타석 이용시간 자동 관리** — 입장 시 이용 세션 생성, 종료 10분/3분 전
   경고, 연장 요청·처리, 종료 시각 도달 시 자동 종료·타석 반납. 시간이
   지나도 반납되지 않는 세션을 스스로 정리하는 자가치유(self-heal) 로직
   포함.
5. **타석 PC 시간제어 에이전트** (자체 개발 Windows 프로그램, Electron) —
   각 타석 PC에 상주하며 남은 이용시간 오버레이 표시, 종료 임박 경고,
   연장 요청, 시간 종료 시 화면 잠금, 이용 종료 후 일정 시간 뒤 PC 자동
   종료까지 수행. 서버와 주기적으로 통신하여 항상 최신 세션 상태를 반영.
6. **매장 로컬 제어기** (자체 개발 Windows 프로그램, PowerShell) — 클라우드
   서버가 매장 내부망(사설 IP)의 자동화 서버에 직접 접근할 수 없는 구조적
   제약을, 매장에 상시 설치된 제어기가 서버에 준비 명령을 주기적으로
   조회(polling)하여 가져가고 매장 내부에서 실행하는 방식으로 해결한
   독자적 아키텍처.
7. **IoT 전원 자동화** — 입장 시 타석 PC(Wake-on-LAN), 프로젝터, 조명 등을
   자동 점등. Home Assistant를 매개로 Tapo 스마트플러그, 소니 프로젝터
   네트워크 제어(PJ Talk), 헤이홈 기기를 통합 제어.
8. **관리자 대시보드** — 타석 이용 현황, 각 타석 PC 전원 온라인/오프라인
   상태(에이전트 통신 여부 기반), 종료 확인 필요 알림, 예약 현황을 단일
   화면에서 실시간 관제. 예약관리 화면은 최신 예약이 위로 오도록 정렬.
9. **관리자 수동 입장/종료** — 반무인 운영(관리자 현장 응대)을 위한 수동
   처리 API. 관리자가 이용을 종료하면 연결된 예약도 함께 종료 처리되어
   키오스크에서 해당 타석이 즉시 재사용 가능한 상태로 반영된다.

## 3. 창작성 및 독립성

- 본 프로그램의 전체 소스코드는 저작자가 직접 작성하였으며, 타사 상용
  프로그램의 소스코드를 복제하거나 개조한 부분이 없다.
- 화면 구성(UI), 브랜드 명칭(VISTA Park Golf Connect), 아이콘, 색상 체계
  (밝은 배경 + VISTA 그린)는 자체 설계이다.
- **클라우드 서버 ↔ 매장 내부망(사설 IP) 간 통신 제약을 해결하기 위해
  고안한 "매장 로컬 제어기의 명령 폴링(pull) 아키텍처"는 본 프로그램의
  독자적 설계로, 타 예약·POS 솔루션에서 흔히 채택하는 방식이 아니다.**
  브라우저의 HTTPS→사설망 혼합 콘텐츠 차단 문제와 매장 자동화 서버를
  인터넷에 노출하지 않아도 되는 보안상 이점을 동시에 만족하도록 자체
  설계하였다.
- 사용한 외부 구성요소는 모두 공개 라이선스(MIT, Apache-2.0, ISC)의
  오픈소스 라이브러리이며, 목록과 라이선스는 `direct-production-evidence.md`
  4절에 명시하였다. 오픈소스 라이브러리는 도구로 사용되었을 뿐 프로그램의
  창작적 표현(화면 구성, 업무 로직, 데이터 구조, 자동화 아키텍처)은 전부
  자체 저작물이다.
- 개발 전 과정이 Git 버전관리 이력(2026-06-14 최초 커밋부터 2026-08-11
  현재까지, 총 52개 커밋)으로 보존되어 있어 창작 과정을 시점별로 증빙할
  수 있다.

(한국저작권위원회 공식 안내문 확인 결과, 소스코드는 **인쇄물이 아니라
CD-ROM/DVD 등 전자적 기록매체**로 제출한다. 창작사실을 일부만으로도
입증 가능하면 발췌 제출 가능하나, 본 프로그램은 전체 소스 규모가 크지
않아 **전체 소스코드를 그대로 제출**하는 것으로 준비했다. 실제 제출
