# 저작권 등록 제출 패키지

작성일: 2026-08-11

이 폴더는 **VISTA Park Golf Connect 프로그램 저작권 등록**을 실제로
접수하기 위한 자료 모음입니다. 한국저작권위원회가 공식 배포한 신청
안내문을 직접 확인하여 실제 절차·서식 항목에 맞춰 준비했습니다.

## 순서대로 보세요

1. **`00-제출-체크리스트.md`** ← 먼저 이것부터. 무엇이 준비됐고, 무엇을
   직접 채워야 하는지 정리되어 있습니다.
2. `01-프로그램등록신청서-작성내용.md` — 신청서에 옮겨 적을 내용
3. `02-프로그램등록신청명세서-작성내용.md` — 명세서에 옮겨 적을 내용
4. `03-복제물-CD라벨.md` — CD/USB 케이스에 붙일 라벨
5. `VISTA-Park-Golf-Connect-소스코드복제물.zip` — 실제 제출용 소스코드
   (CD나 USB에 구워서 제출, 비밀키·토큰 제외 확인됨)

## 핵심 요약

- 제출 방법: 온라인(cros.or.kr, 공인인증서 필요) / 위원회 방문 / 우편
- 필요 서류: 신청서 + 명세서 + 소스코드 복제물(CD/DVD)
- **가장 먼저 결정할 것: 한글 제호** (국어기본법상 필수, 초안 "비스타
  파크골프 커넥트" 확정 여부)
- 화면 캡처 5종은 이 도구가 이미지 캡처를 지원하지 않아 직접 캡처
  필요(체크리스트에 URL 정리됨, 약 5분 소요)
