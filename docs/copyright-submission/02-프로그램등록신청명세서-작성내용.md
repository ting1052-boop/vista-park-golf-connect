# 프로그램등록신청명세서 — 작성 내용 (별지 제4호의2서식용 초안)

실제 신청서(온라인 입력화면 또는 다운로드한 `프로그램등록신청명세서.hwp`)에
그대로 옮겨 적을 수 있도록 항목별 내용을 채운 초안입니다.

---

## 프로그램종류코드

```
(확인 필요) — 응용 소프트웨어(예약/매장관리/POS 유사 계열)로 분류
예상되나, 정확한 5자리 코드는 cros.or.kr 신청 화면 또는 코드표에서
직접 조회해 기재해야 합니다. (위원회 배포 안내문에 코드표가 이미지/표
형태로만 있어 본 문서에는 텍스트로 옮기지 못했습니다.)
```

## ① 적용분야

```
매장 운영관리 소프트웨어 (스크린파크골프 무인·반무인 매장 운영,
예약·입장·타석 이용시간 관리 및 설비 자동제어)
```

## ② 주요내용

**본 프로그램의 특징**
```
스크린파크골프 매장의 예약·입장·이용시간 관리와 매장 설비(타석 PC,
프로젝터, 조명) 전원 자동제어를 하나의 시스템으로 통합한 무인매장
운영 소프트웨어. 특히 클라우드 서버가 매장 내부 사설망의 자동화
서버에 직접 접근할 수 없는 구조적 제약을, 매장에 상시 설치된
'로컬 제어기' 프로그램이 서버의 명령을 주기적으로 조회(polling)하여
가져가 매장 내부에서 실행하는 방식으로 해결한 독자적 아키텍처를
적용함.
```

**주요기능**
```
1. 고객 모바일 예약(PWA) — 매장/일정/인원/이용시간 선택, 이중예약
   방지(응용 계층 + 데이터베이스 배타 제약조건의 이중 구조)
2. 매장 입구 태블릿 키오스크 — 예약 조회 입장, 예약 없는 고객의
   현장 즉시이용(후불) 처리, 직원 개입 없이 동작
3. 타석 이용시간 자동 관리 — 입장 시 세션 생성, 종료 임박 경고,
   연장 요청 처리, 시간 종료 시 자동 종료 및 타석 반납
4. 타석 PC 상주 에이전트(Electron) — 각 타석 PC에서 남은 시간
   표시, 종료 시 화면 잠금, 일정 시간 후 PC 자동 종료
5. 매장 로컬 제어기(PowerShell) — 서버의 장비 준비 명령을 매장
   내부에서 안전하게 실행(타석 PC 전원, 프로젝터, 조명 제어)
6. 관리자 대시보드 — 타석 이용 현황, 타석 PC 전원 온라인/오프라인
   실시간 표시, 예약·미퇴장 등 운영 알림 관제
```

**사용방법**
```
관리자는 PC 웹 브라우저로 대시보드(/admin/*)에 로그인하여 매장을
관제한다. 고객은 모바일로 예약(/member/app)하거나 매장 입구
태블릿 키오스크(/kiosk/entrance)에서 직접 입장 처리한다. 타석
PC와 매장 자동화 서버에는 각각 자체 개발 상주 프로그램이 설치되어
사람 개입 없이 세션·장비 상태를 서버와 동기화한다.
```

**판매구분**
```
(확인 필요) — 자사 매장(비스타파크골프 시흥점) 자체 운영용으로 개발.
향후 타 가맹점 라이선스 제공 계획이 있다면 "판매용"으로, 없다면
"비매(자가사용)"로 표시.
```
