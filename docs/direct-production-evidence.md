# 직접생산 확인 증빙 자료

프로그램명: VISTA Park Golf Connect · 버전: 2.0 (현행) · 작성일: 2026-08-11 (최초 작성 2026-07-02)

## 1. 직접생산 사실 요약

본 프로그램은 (기입: 업체명 — HH Square)이 기획·설계·개발·시험·배포·운영의
전 과정을 직접 수행한 자체 개발 소프트웨어이다.

- 외주 개발 없음. 타사 상용 솔루션의 재판매·개조가 아님.
- 소스코드 전체를 자체 보유하며 버전관리 시스템(Git)으로 개발 전
  과정이 기록되어 있음 (2026-06-14 최초 커밋 ~ 2026-08-11 현재, 총 52개 커밋).
- 프로그램 명칭, 화면 구성, 업무 로직, 데이터베이스 설계, 타석 PC
  상주 프로그램, 매장 자동화 아키텍처 전부 자체 창작물임.
- 실제 매장(시흥점 쇼룸)에 설치되어 실물 장비(타석 PC, 프로젝터, 조명,
  Home Assistant 서버)와 연동 실증을 완료함.

## 5. 자체 시험 수행

개발 과정에서 수행한 기능 시험의 시나리오와 실제 결과는
`docs/test-scenarios.md`에 기록하였다. 대표 항목:

- 고객 예약 전체 흐름 (입력 → 확인 → 확정 → DB 저장) 실기 검증
- 이중예약 차단: 응용 계층·DB 계층 각각 실제 재현 시험으로 확인
- 관리자 인증: 미인증 접근 시 로그인 화면 리다이렉트 확인
- 키오스크 입장(예약 조회 입장 / 현장 즉시이용) 실제 매장 실행 검증
- 타석 PC 에이전트: 실제 시흥점 타석 PC에 설치, 남은시간 표시·종료
  경고·연장·화면 잠금·종료 후 PC 자동 종료까지 실기기 검증
- 매장 로컬 제어기: 명령 큐 적재→폴링→소니 프로젝터 실제 전원 제어까지
  실증(순서: 프로젝터 ON → 15초 대기 → PC Wake-on-LAN)
- PWA: 매니페스트/아이콘 응답, 홈 화면 설치 확인
