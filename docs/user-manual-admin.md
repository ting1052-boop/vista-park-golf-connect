# VISTA Park Golf Connect 관리자 사용 설명서

버전: 2.0 (현행) · 작성일: 2026-08-11 (최초 작성 2026-07-02)
대상: 본사관리자, 매장관리자, 직원

## 1. 시작하기

### 1.1 접속

PC 웹 브라우저(Chrome 권장)에서 아래 주소로 접속한다.

- 운영: `https://vista-park-golf-connect.vercel.app/admin/dashboard`

로그인하지 않은 상태로 관리자 화면에 접속하면 자동으로 로그인
화면으로 이동한다.

### 1.2 로그인

1. 이메일과 비밀번호를 입력하고 **로그인** 버튼을 누른다.
2. 로그인에 성공하면 원래 접속하려던 화면(기본: 대시보드)으로
   이동한다.
3. 비밀번호가 틀리면 "이메일 또는 비밀번호가 올바르지 않습니다"
   안내가 표시된다.

> 관리자 계정은 본사에서 발급한다. 계정 발급·비밀번호 초기화는
> 본사 운영팀(Supabase 콘솔 관리자)에 요청한다.

### 1.3 로그아웃

왼쪽 메뉴 하단의 **로그아웃** 버튼을 누르면 세션이 종료되고
로그인 화면으로 돌아간다. 공용 PC에서는 사용 후 반드시 로그아웃한다.

## 2. 대시보드

접속 주소: `/admin/dashboard`

- **현재 이용 중 / 입장 대기 / 사용 가능 / 점검 카드** — 타석
  상태별 집계. 타석 상태가 바뀌면 화면이 실시간 갱신된다.
- **타석 카드의 "PC 켜짐/꺼짐" 표시** — 각 타석 카드 오른쪽 위에
  🟢 켜짐 / ⚪ 꺼짐 배지가 표시된다. 그 타석 PC의 에이전트 프로그램이
  최근(약 2분 이내) 서버와 통신했으면 켜짐으로 표시된다. 배지에
  마우스를 올리면 마지막 통신 시각을 볼 수 있다. **꺼짐으로 표시되면
  그 타석 PC의 전원이나 에이전트 실행 상태를 확인한다.**
- **확인 필요한 운영 알림** — 미퇴장(종료시각 지났지만 반납 안 됨),
  종료 임박, 노쇼 확인, 장비 전원 확인 등 조치가 필요한 항목.
  **확인 처리** 버튼으로 정리한다. 종료시각이 지나고도 오래 방치된
  세션은 이 화면을 열 때 자동으로 정리되므로, 미퇴장 알림이 계속
  쌓이지 않는다.
- **빠른 실행** — 입장 세션 시작, 매장 준비 ON, 타석 배정,
  제어 로그 출력.

## 3. 매장관리

접속 주소: `/admin/stores`

- **신규 등록**: 왼쪽 폼에 매장코드(예: VISTA-SH), 매장명, 주소,
  전화번호, 타석수, 운영상태를 입력하고 **Supabase에 추가**를 누른다.
- **수정/삭제**: 목록의 각 행에서 **수정** / **삭제** 버튼 사용.
- 타석수를 입력하면 해당 수만큼 타석관리에 타석 레코드가 자동
  생성·동기화된다.

## 4. 타석관리

접속 주소: `/admin/bays`

- 타석코드(예: A-01), 표시명, 상태, 메모를 관리한다.
- 상태 값: `available`(사용 가능) / `in_use`(이용 중) /
  `waiting`(입장 대기) / `maintenance`(점검).
- 타석 상태는 고객 예약 화면의 "예약 가능 타석" 계산에 바로
  반영된다. 점검이 필요한 타석은 `maintenance`로 바꾸면 고객이
  예약할 수 없다.

## 5. 장비관리

접속 주소: `/admin/devices`

- 매장 내 장비(프로젝터, 리시버, 키오스크 등)의 코드, 이름, 종류,
  상태, 최근 점검일을 관리한다.

## 6. 회원관리

접속 주소: `/admin/members`

- 닉네임, 전화 뒤 4자리, 가입경로, 연령대, 메모를 관리한다.
- 개인정보 최소 수집 원칙에 따라 전체 전화번호는 저장하지 않는다.

## 7. 예약관리

접속 주소: `/admin/reservations`

- 고객 앱 예약과 전화/현장 예약을 한 목록에서 관리한다. **목록은
  최신 예약이 맨 위에 오도록 정렬**된다.
- **등록**: 예약자명, 시작 시각, 타석코드, 인원, 채널, 상태를
  입력해 현장/전화 예약을 직접 추가할 수 있다.
- **수정**: 타석 재배정, 상태 변경(확정/입장/취소/노쇼)에 사용한다.
- 같은 타석의 시간이 겹치게 배정하면 저장되지 않고
  "선택한 타석과 시간대가 이미 예약되어 있습니다" 안내가 표시된다.
  이는 데이터베이스 차원의 안전장치로, 화면을 우회해도 겹침 예약은
  만들어지지 않는다.
- 90분 이상 또는 5명 이상 고객 예약은 "승인 대기" 상태로 접수된다.
  내용 확인 후 상태를 확정으로 변경한다.

## 8. 무인제어

접속 주소: `/admin/automation`

- 자동화 시나리오 4종: **예약 입장 준비** (로비 조명·냉난방·타석
  조명·키오스크 ON) / **타석 이용 시작** / **이용 종료 정리** /
  **마감 전체 OFF**.
- **시흥점 쇼룸 실기기 테스트**: 헤이홈·Tapo·소니 프로젝터 장비를
  대상으로 예약 준비 → 이용 시작 → 종료 정리 흐름을 검증하는 패널.
  실행에는 테스트 비밀번호가 필요하다.
- 예약 5분 전 자동 준비는 서버 API(`/api/automation/reservation-prepare`)
  가 담당하며, 처리 결과는 예약별 `automation_prepare_status`로
  기록된다.
- **실제 운영에서는 키오스크 입장 시 매장 로컬 제어기가 자동으로
  장비를 준비한다** (10절 참조). 이 화면의 자동화 패널은 주로
  개별 테스트·점검용으로 사용한다.
- 출입문 제어는 안전 검토 후 도입 예정(1차 제외).

## 9. 타석 PC 시간제어 에이전트

각 타석 PC에는 자체 개발 상주 프로그램(에이전트)이 항상 실행되어
있으며, 별도 관리 화면 없이 게임 화면 위에 오버레이로 작동한다.

- 이용 세션이 시작되면 타석 화면 위에 **남은 시간**이 표시된다.
- 종료 10분 전 / 3분 전에 경고 팝업이 뜨며, 고객이 **연장** 버튼을
  누르면 요청이 서버로 전달된다.
- 이용 종료 시각이 지나면 화면이 잠기고, 새 이용이 없으면 일정
  시간 후 PC가 자동으로 꺼진다.
- 새 타석 PC에 설치할 때는 실행파일을 복사해 실행하고, 처음 한
  번 타석 번호를 선택하면 된다.
- 각 타석 PC가 정상 작동 중인지는 **대시보드의 "PC 켜짐/꺼짐"
  표시**(2절)로 원격에서 확인할 수 있다.

## 10. 매장 로컬 제어기 (무인 자동화)

매장 안에 상시 켜져 있는 컴퓨터(Home Assistant 서버)에 자체 개발
제어기 프로그램이 항상 실행되며, 별도 관리 화면 없이 백그라운드로
동작한다.

- 키오스크에서 고객이 입장하면, 이 제어기가 자동으로 해당 타석의
  PC 전원과 프로젝터를 켠다(순서: 프로젝터 ON → 15초 대기 → PC
  전원 켜기).
- 클라우드 서버는 매장 내부망에 직접 접근하지 않고, 제어기가
  주기적으로 서버에 "처리할 준비 명령이 있는지" 확인해 가져가는
  방식으로 동작한다. 인터넷이 느리거나 매장 내부망 구성이 바뀌어도
  안전하게 재시도된다.
- 처리 결과(성공/실패)는 무인제어 화면의 제어 로그에서 확인할 수
  있다.
- 이 프로그램은 매장의 Home Assistant 컴퓨터가 부팅될 때 자동으로
  함께 실행되도록 설정되어 있어, 정전 후 재부팅 등에도 별도 조작이
  필요 없다(단, Home Assistant 자체의 자동 실행 설정은 별도 확인).

## 11. 기타 화면

경기기록 / 랭킹 / 대회운영 / 조인모집 / 리포트 화면은 1차 MVP에서
화면 구조가 준비된 상태이며, 실 데이터 연동은 2차 확장에서
제공된다.

## 12. 자주 묻는 문제

| 증상 | 조치 |
| --- | --- |
| 관리자 화면이 로그인으로 계속 돌아감 | 계정 미발급 또는 세션 만료. 본사에 계정 확인 요청 후 재로그인 |
| 고객 화면에 "예약 가능 타석 0개" | 해당 시간대에 모든 타석이 예약됨(정상) 또는 타석 상태가 점검/이용중인지 타석관리에서 확인 |
| 예약 저장 시 "이미 예약되어 있습니다" | 다른 예약과 시간이 겹침. 타석 또는 시간을 바꿔 저장 |
| 매장 저장이 안 됨 | 매장코드 중복 여부 확인 (매장코드는 고유값) |
| 대시보드에서 특정 타석이 계속 "PC 꺼짐"으로 보임 | 그 타석 PC가 꺼져 있거나 에이전트 프로그램이 실행되지 않은 상태. 현장에서 PC·에이전트 실행 확인 |
| 키오스크 입장 후 장비가 자동으로 켜지지 않음 | 매장 로컬 제어기가 실행 중인지 확인(Home Assistant 컴퓨터에서 확인), 활성화 설정(`STORE_CONTROLLER_ENABLED`) 여부 확인 |
| 관리자가 이용 종료했는데 키오스크에서 그 타석이 계속 막혀 있음 | 2026-08-10 이후 배포에서 자동 해결됨. 이전 버전이면 최신 배포로 갱신 |
