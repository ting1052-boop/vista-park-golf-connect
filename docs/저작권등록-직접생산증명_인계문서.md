## 3. 프로그램 구성 — 4개 독립 프로그램의 통합 시스템

이 시스템은 단일 웹앱이 아니라, **역할이 다른 4개의 자체 개발 프로그램**이
하나의 서비스로 유기적으로 동작하는 구조다.

1. **웹 서버** (Next.js/Supabase) — 고객 모바일 예약, 관리자 대시보드,
   예약·세션·자동화 데이터 관리
2. **입구 키오스크** (`/kiosk/entrance`) — 매장 입구 태블릿에서 예약
   조회 입장, 현장 즉시 이용(후불 계좌이체)까지 직원 개입 없이 처리
3. **타석 PC 상주 에이전트** (Electron, Windows 실행파일) — 각 타석
   PC에 상시 실행되며 남은 이용시간 표시, 종료 경고, 연장 요청, 시간
   종료 시 화면 잠금과 PC 자동 종료 수행
4. **매장 로컬 제어기** (PowerShell, Windows 상시 프로세스) — 클라우드
   서버가 매장 내부 사설망 자동화 서버(Home Assistant)에 직접 접근할
   수 없는 구조적 제약을, 매장에 상시 설치된 제어기가 서버의 명령을
   주기적으로 가져가 매장 내부에서 실행하는 방식으로 해결한 **독자
   설계 아키텍처**. 입장 시 타석 PC(WOL)·프로젝터(소니 PJ Talk
   네트워크 제어)·조명(헤이홈) 등을 자동으로 준비한다.

## 4. 창작성·직접생산(자체개발) 증빙 요지

- 전체 소스코드(4개 프로그램 전부)를 저작자가 직접 작성했으며, 타사
  상용 프로그램의 소스를 복제·개조한 부분이 없음.
- 화면 구성(UI), 브랜드 명칭·아이콘, 색상 체계(VISTA 그린), 업무 로직,
  데이터 구조, **자동화 아키텍처(매장 로컬 제어기의 명령 폴링 방식)**
  전부 자체 설계.
- 사용한 외부 구성요소는 모두 공개 라이선스(MIT, Apache-2.0, ISC)의
  오픈소스 라이브러리로, 도구로만 사용됨. 창작적 표현은 전부 자체
  저작물. (라이선스 목록: 저장소 `docs/direct-production-evidence.md`)
- **개발 전 과정이 Git 버전관리 이력(2026-06-14 최초 커밋 ~ 총 52커밋)
  으로 보존**되어 시점별 창작 과정을 증빙 가능 — 직접생산 증명의 핵심
  근거.
- 실제 매장(시흥점 쇼룸)에 설치되어 실물 타석 PC·프로젝터·조명·Home
  Assistant 서버와 연동 실증까지 완료됨(테스트 결과: `docs/test-scenarios.md`).
